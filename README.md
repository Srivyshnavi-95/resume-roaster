# 🔥 Resume Roaster

Is your resume hireable or just hilarious? 😂

Resume Roaster is an AI tool that roasts your resume like a friend would - honest, funny, and actually helpful!

### 🚀 Live Demo
👉 https://resume-roaster-eif9.vercel.app/

### ✨ Features
- 📄 Upload your Resume PDF
- 🔥 Get an Overall Roast Score
- 🤖 ATS Compatibility Check
- 📊 Content & Metrics Feedback
- 📥 Downloadable Roast Report

### 🛠️ Built With
- AI + Gemini API
- Deployed on Vercel
